# Entdeckerporträts

Dieser Ordner ist für spätere, nachweisbar frei nutzbare Porträts vorgesehen. In Phase 1/2
wurden bewusst keine KI-generierten Pseudoporträts realer Wissenschaftler erzeugt.
Beim Ergänzen eines Porträts bitte Urheber, Lizenz und Originalquelle in
`data/element-content.js` dokumentieren.
